# Historical saved-data bundle

Filename: `actR-saved-results.zip`

Download: https://github.com/ivorysj-gif/actR-publication/releases/download/v1.0.0/actR-saved-results.zip

From the repository root, run `Rscript install_dependencies.R` followed by `Rscript download_saved_results.R` to verify the checksum and extract safely. See README for RStudio commands. The helper refuses to overwrite an existing extraction.

Extract into the repository root; it creates `saved_results/`, `reference_originals/`, and `outputs/`. These directories are intentionally ignored by Git.

Keep the supplied `outputs/publication/` previews. The revised default run writes new figures into `outputs/reproduced/`.
